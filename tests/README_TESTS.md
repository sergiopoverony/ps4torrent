# Тесты (запускаются на компьютере, без консоли)

Папка `ft/` должна лежать как `/tmp/ft/` (пути зашиты в скриптах): `cp -r tests/ft/* /tmp/ft/`.
Для тестовой раздачи нужны данные в `/tmp/ft/src/<имя раздачи>/` (их делает `mk.py`; сами торренты лежат в `torrents_src/`,
размеры: Game One 3 файла (2000000, 1300000, 300001), Big8M 2 файла (26000000, 9000000), Many 1 файл 70 МБ, Chk 400 МБ).
Сначала `bash tests/build_tests.sh` (собирает `/tmp/ft/daemon_*`), `seeder.py` / `seeder_ctl.sh` поднимают тестового сида.

| Набор | Запуск | Ожидание |
|---|---|---|
| API | `bash /tmp/ft/api_run.sh` | 32/32 |
| Удаление | `delete_run.sh` | 15/15 |
| Запуск (автозапуск выкл.) | `auto_run.sh` | 16/16 |
| Перезапуск / вынимание флешки | `auto2_run.sh` | 13/13 |
| Зависший диск (поток записи) | `wr_run.sh` | 13/13 |
| Хранилище (память консоли, место) | `storage_run.sh` | 27/27 |
| Несколько накопителей | `mounts_run.sh` | 19/19 (проверка про иконку устарела и убрана) |
| Память о сессии | `session_run.sh` | 17/18: известный артефакт теста (неверная точка отсчёта, не ошибка программы) |
| Выбор файлов | `sel_run.sh` | 25/25 |
| Сохранение кусков | `part_test.sh`, `part_test2.sh` | см. вывод (restored 300 blocks, IDENTICAL) |
| Устаревший дескриптор / сон | `fd_run.sh` | 13/13 |

| Медленное удаление файлов (поток) | `python3 slowdel_test.py` (хук `/tmp/ft/unlink_cost`) | 8/8 |
| Страница (Node) | `node page/jstest2.js`, `node page/jstest5.js` | 20/20, 34/34 |

Каждый `*_run.sh` пишет результат в `<имя>.result`. Тесты на ThreadSanitizer: `tsan_net_run.sh` (бинарник `daemon_tsan`
собирается как остальные, но с `-fsanitize=thread` вместо address,undefined).
Устаревшие/неиспользуемые: `icon_*`, `diag_*` (функции убраны или меняются), `wr_dbg*`.
